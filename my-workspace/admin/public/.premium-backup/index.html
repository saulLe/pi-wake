Pi 本地管理界面

管理你的 Pi 配置、资源、会话与模型。所有数据都在本机，不联网、不外传。

环境信息

ℹ
使用提示

这个界面直接读写 Pi 的配置文件。默认是只读的，需要修改时点左下角「解锁编辑」。改完配置后，在 Pi 终端里执行 /reload 让改动生效。所有写操作都会先备份到 admin/.backups/。
