# 环境与准备清单

> 结论：三层准备——环境、代码、知识。Skill / Extension 路线今天就能开工，SDK 嵌入或 Fork 才需要额外工程化投入。

## 一、环境准备（必做）

| 项目 | 要求 | 本地实测 |
|---|---|---|
| Node.js | ≥ 22.19 | v22.22.2 ✅ |
| 包管理器 | npm / pnpm / bun（官方四种都支持） | npm 10.9.7 ✅ |
| Git | 任意版本 | 2.49.0 ✅ |
| 模型账号 | Anthropic / OpenAI / Google / Kimi / Ollama 任一 | 待 `/login` 配置 |
| 编辑器 | VS Code / Cursor 等 | 写 TypeScript 扩展用 |

## 二、代码与工程准备

```bash
git clone https://github.com/earendil-works/pi.git
cd pi
npm install --ignore-scripts      # 必须带这个参数
npm run build
./test.sh                         # 确认基线正常
```

本地因 GitHub 直连被代理拦截（502 / HTTP2 framing error），改用 codeload 下载源码 tar.gz（16MB）导入。
依赖用国内镜像加速：`npm install --ignore-scripts --registry=https://registry.npmmirror.com`。

仓库里二开的主战场：

| 路径 | 用途 |
|---|---|
| `packages/coding-agent/docs/` | 扩展、skills、prompts、themes、packages、RPC、models 全套文档 |
| `packages/coding-agent/examples/extensions/` | 50+ 示例：sub-agent、plan mode、权限门、路径保护、SSH、沙箱等 |
| `packages/coding-agent/src/core/system-prompt.ts` | 极简系统提示词，理解上下文怎么组装 |

## 三、知识准备（按优先级）

1. **扩展机制**——TypeScript 模块怎么注册工具、命令、快捷键、事件钩子
2. **Skills 规范**——Agent Skills 规范，按需加载不撑爆上下文
3. **上下文工程**——`AGENTS.md` / `SYSTEM.md` / compaction 机制
4. **Pi packages**——extensions + skills + prompts + themes 打包分发

## 四、按路线追加

| 路线 | 额外准备 |
|---|---|
| Skill | 无，写好 Markdown 放 `~/.pi/agent/skills/` 或项目 `.pi/skills/` 即可 |
| Extension | TypeScript 基础 + 读 `extensions.md` + 从示例改起（别从零写） |
| SDK / RPC | 确定宿主语言（RPC 是 stdin/stdout JSON，非 Node 也能接）+ 设计会话与权限边界 |
| Fork | 阅读 RFCs 和 `AGENTS.md`，规划合并策略；仓库依赖 pin 精确版本（`save-exact=true`），升级看 changelog |

## 五、版本锁定提醒

项目 2025 年 8 月建仓、迭代快，扩展 API 有 breaking change 风险。正式二开前先锁定版本：

- Nix：`nix profile add github:earendil-works/pi/<tag>`
- npm：锁版本，别直接跟 `main`

本地导入的基线是 commit `73315ff`（版本 1.6.1，2026-11-26 导入）。上游大更新时重新导入并 merge `my-workspace/`。
