# Pi 项目概览

> 来源：Pi 官方仓库 README 与官网 pi.dev，核对日期 2026-11-26。

## 一句话定位

Pi 是一个**极简、可扩展、可高度自定义的 AI agent harness（终端编码智能体）**。
核心理念：**Adapt Pi to your workflows, not the other way around**（让 Pi 适配你的工作流，而不是反过来）。

## 设计哲学

- **默认强大但克制**：内置强默认能力，但刻意**不做** sub-agent、plan mode、权限弹窗、内置 todo、后台 bash。
- **原语而非功能**：其他 agent  baked-in 的功能，Pi 当作"工作流选择"交给扩展和包来实现。
- **可自我改造**：可以直接让 Pi 修改自己，然后 `/reload` 生效，无需重启。
- **安全边界显式化**：默认没有内置权限系统，以启动用户的权限运行；需要隔离时用容器或扩展补确认流。

## 架构：npm 包拆分（monorepo）

本地 `packages/` 下的核心包：

| 包 | 作用 |
|---|---|
| `pi-ai` | 统一多提供商 LLM API |
| `pi-agent-core` | Agent 运行时：工具调用循环 + 状态管理 |
| `pi-coding-agent` | 交互式 coding agent CLI（主入口） |
| `pi-tui` | 差分渲染终端 UI 库 |
| `pi-telemetry` | 厂商中立遥测合约与适配器 |
| `chord` | 跨进程应用对象运行时（contracts/documents/store/plugins/HTTP/workers） |
| `pi-durable` | 持久化对话、任务、文档运行时 |

这样拆分后可以只消费其中一层（比如只用 `pi-ai` 做统一 LLM 层，或只用 `pi-agent-core` 嵌入自己的应用），不必吃下整个 CLI。

架构分层图见 `架构图-分层.svg`。

## 关键特性

### 模型支持：15+ 提供商，数百个模型

Anthropic、OpenAI、Google、Azure、Bedrock、Mistral、Groq、Cerebras、xAI、Hugging Face、Kimi For Coding、MiniMax、NVIDIA、OpenRouter、Ollama 等。
- 鉴权：API Key 或 OAuth（支持 Claude Pro/Max、ChatGPT Plus/Pro、GitHub Copilot 订阅账号）
- 会话中 `/model` 或 `Ctrl+L` 切换模型，`Ctrl+P` 循环收藏模型
- 自定义 provider / model：`models.json` 或扩展

### 四种运行模式

| 模式 | 用法 |
|---|---|
| 交互 TUI | 终端里的完整交互体验 |
| Print / JSON | `pi -p "query"` 脚本用；`--mode json` 事件流 |
| RPC | stdin/stdout 上的 JSON 协议，非 Node 集成 |
| SDK | 嵌入自己的应用（OpenClaw 是真实集成案例） |

### 树状可分享会话

- 会话以树存储，`/tree` 回到任意历史节点分叉，所有分支在一个文件里
- `/export` 导出 HTML，`/share` 上传 GitHub gist 得到可渲染链接
- 可按消息类型过滤、给条目加书签

### 上下文工程

- **极简 system prompt**：源码在 `packages/coding-agent/src/core/system-prompt.ts`
- **AGENTS.md**：启动时从 `~/.pi/agent/`、父目录、当前目录加载项目指令
- **SYSTEM.md**：按项目替换或追加默认系统提示
- **Compaction**：接近上下文上限时自动摘要，可用扩展自定义（主题式、代码感知、换摘要模型）
- **Skills**：遵循 Agent Skills 规范，按需加载，渐进式披露不撑爆缓存
- **Prompt templates**：Markdown 文件，`/name` 展开
- **Dynamic context**：扩展可在每轮前注入消息、过滤历史、实现 RAG 或长期记忆

###  steer / follow-up

- `Enter` 发送 steering 消息（当前工具后送达，打断剩余工具）
- `Alt+Enter` 发送 follow-up（等 agent 完成后处理）

## 扩展机制（三层自定义）

| 层级 | 形式 |
|---|---|
| 轻量 | prompt templates、themes |
| 中间 | skills（指令 + 脚本 + 参考资料 + 资产） |
| 重量 | extensions（TypeScript 模块，可注册工具、命令、快捷键、UI、事件钩子、provider） |

再往上可打包成 **Pi packages**，通过 npm 或 git 分发分享。

## 上手命令

```bash
curl -fsSL https://pi.dev/install.sh | sh        # 官方安装脚本（pin 依赖）
npm install -g --ignore-scripts @earendil-works/pi-coding-agent   # 或 npm 装
cd 你的项目 && pi
/login                                          # 连接模型提供商
```

Nix：`nix profile add github:earendil-works/pi/stable`，`nix profile upgrade pi` 升级，`pi update` 不适用于 Nix 安装。

## 与 Claude Code / Cursor 的对比

Pi 更像一个**可组装的骨架**：内核极简、完全可改造、不预设工作流；代价是很多能力要自己装包或写扩展，安全边界也要自己管。
Claude Code / Cursor 等是**全家桶**：开箱功能多，但更重、更黑盒、更难改造。
